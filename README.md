# Fileodon Distribution Listener

The Fileodon Distribution Listener is an ASP.NET Core service that transfers files
between two SFTP servers on behalf of the Fileodon API. It accepts a transfer job,
queues it for background processing, and exposes progress while the files are copied.

## What you need

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) for development or building
- Linux with `systemd` for the supplied production installer
- Network access to both SFTP endpoints
- The Fileodon Master API JWT public key

## Quick start

From the `FileodonDistributionListener` directory:

```powershell
dotnet restore
dotnet build
dotnet run --project .\FileodonDistributionListener
```

The development profile listens on `http://localhost:5096`. The service requires a
JWT public key before it starts. Set `Jwt__PublicKeyPath` to a PEM file, or place the
key at `FileodonDistributionListener\public.pem`:

```powershell
$env:Jwt__PublicKeyPath = "C:\path\to\public.pem"
dotnet run --project .\FileodonDistributionListener
```

Check that the service is running:

```powershell
Invoke-RestMethod http://localhost:5096/health
```

For a complete Linux installation, including the systemd service and automatic public
key download, see [InstallationGuide.md](InstallationGuide.md).

## API

All transfer endpoints require a bearer token issued by the Fileodon Master API.

### Create a transfer

`POST /api/transfers` returns `202 Accepted` and a job snapshot. Each SFTP endpoint
uses an SSH private key in PEM format. The listener uses port `22` when `Port` is
zero or omitted.

```http
POST /api/transfers
Authorization: Bearer <master-api-jwt>
Content-Type: application/json

{
  "source": {
    "host": "source.example.com",
    "port": 22,
    "username": "fileodon-source",
    "privateKeyPem": "-----BEGIN OPENSSH PRIVATE KEY-----\n...\n-----END OPENSSH PRIVATE KEY-----"
  },
  "destination": {
    "host": "destination.example.com",
    "port": 22,
    "username": "fileodon-destination",
    "privateKeyPem": "-----BEGIN OPENSSH PRIVATE KEY-----\n...\n-----END OPENSSH PRIVATE KEY-----"
  },
  "files": [
    {
      "sourceRemotePath": "/exports/example.zip",
      "destinationRemotePath": "/incoming/example.zip",
      "length": 1048576
    }
  ]
}
```

`length` is used for progress reporting and must be non-negative. The listener
validates that at least one file is supplied, but it does not persist jobs across
restarts.

### Poll a transfer

```http
GET /api/transfers/<job-id>
Authorization: Bearer <master-api-jwt>
```

Jobs move through `Queued`, `Running`, `Completed`, or `Failed`. The response
includes total and uploaded bytes, a percentage, per-file progress, and an error
message when applicable.

### Health check

`GET /health` does not require authentication and returns:

```json
{ "status": "ok" }
```

## Configuration

Configuration can be supplied through `appsettings.json`, environment variables, or
the production file generated by the installer. ASP.NET Core maps `__` to `:`.

| Setting | Purpose | Default |
| --- | --- | --- |
| `Urls` | Address and port to bind | `http://0.0.0.0:5096` |
| `Jwt__PublicKeyPath` | Fileodon Master API ECDSA public key in PEM format | `public.pem` in the content root |
| `ASPNETCORE_ENVIRONMENT` | Runtime environment | `Production` when installed |

Keep private keys and tokens out of source control. Use HTTPS or a trusted reverse
proxy when the service is reachable outside a private network, because transfer
requests contain SFTP private keys.

## Build a Linux release

The installer can build the application itself. To create a publish directory first:

```powershell
dotnet publish .\FileodonDistributionListener\FileodonDistributionListener.csproj `
  -c Release -r linux-x64 --self-contained false `
  -o .\artifacts\linux-x64
```

Then copy the repository and publish directory to the Linux host and follow the
[installation guide](InstallationGuide.md).

## Development

Build the project from this repository directory:

```powershell
dotnet build .\FileodonDistributionListener\FileodonDistributionListener.csproj
```

There are currently no automated tests in this project. At minimum, verify the
health endpoint and an authenticated transfer against test SFTP servers before
deploying changes.
